# GTA V Natives Documentation

Welcome to the **GTA V Natives Reference** — a comprehensive, searchable documentation site for GTA V's native function database.

## What are Natives?

Natives are the built-in functions in the GTA V engine that can be called from scripts. They provide access to game functionality such as:

- **Player** — Player management, stats, and interactions
- **Vehicle** — Vehicle spawning, modification, and control
- **PED** — Pedestrian AI, appearance, and behavior
- **HUD** — UI elements, notifications, and menus
- **GRAPHICS** — Visual effects, cameras, and rendering
- **WEAPON** — Weapon management and combat
- And many more...

## Features

- 🔍 **Fast Search** — Search across 6000+ natives by name, hash, or description
- 📂 **Organized by Namespace** — Browse natives grouped by their functional category
- 📖 **Detailed Documentation** — View parameters, return values, and code examples
- 🌓 **Dark Mode** — Comfortable reading in any lighting
